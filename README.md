# Patient-Centric Healthcare 5.0 — Streamlit App

An interactive, no-API learning studio for a 150-minute management-development programme for doctors and pharmaceutical professionals.

## Included

- Exactly 60 minutes of evidence-labelled theory
- Seven complete healthcare-AI teaching cases
- Exactly 90 minutes of demonstrations and participant practice
- Four workshop stations
- Eleven copy-ready ChatGPT medical discussion prompts
- Ninety-three-tool medical AI explorer
- Demo-readiness control room
- Ten-question assessment
- Fifty-six-page complete handbook in editable DOCX and print-ready PDF
- Downloadable presentation, facilitator guide, workbook, prompt cards and research matrices

## Run locally

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

macOS/Linux:

```bash
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud

1. Create a GitHub repository and upload this folder without changing its internal structure.
2. Visit <https://share.streamlit.io/> and sign in with GitHub.
3. Select the repository and branch.
4. Set the main file path to `app.py`.
5. Deploy. No API key or secret is required.

## Important safety boundary

This application is for education and workshop facilitation. Use only synthetic/de-identified or approved public information. It does not diagnose, prescribe, replace urgent care, release patient advice or substitute for professional, institutional, legal or regulatory review.

Tool access, pricing, product scope and regulatory status can change. Reopen official links and verify current applicability before every delivery.
